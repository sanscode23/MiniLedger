# MiniLedger

MiniLedger is an application that helps you track money lent to friends.

## Services & Applications

- [Backend (`/backend`)](./backend/README.md): Node.js, Express, TypeScript, Prisma, PostgreSQL, JWT Authentication, Multer Receipt Uploads.
- [Mobile App (`/mobile`)](./mobile/README.md): React Native (Expo), TypeScript, React Navigation, SecureStore, ImagePicker, DatePicker.
